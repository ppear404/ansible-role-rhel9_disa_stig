# Security reporting

Do not post credentials, host inventories, private assessment results, or an
unredacted exploitable configuration in a public issue. Use the repository's
GitHub private vulnerability reporting feature when enabled; otherwise request a
private contact without including vulnerability details.

This project implements a subset of RHEL 9 V2R10 controls. Assessment output and
manual answers are evidence inputs, not certification of system compliance.
Validate changes against your authorization boundary and benchmark revision.
